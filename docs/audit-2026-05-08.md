# External Audit — 2026-05-08

A deliberately hostile external review of the whole project: setup, code
structure, code quality, testing, product quality. Every finding was
verified against the current tree (file:line) before being recorded;
three candidate findings were dropped because the code actually held up
(locale key parity is 289/289 across all five languages; the error banner
renders stable localized copy only; the debug prompt panel is DEV-gated).

Disposition: FIXED here = closed by a commit referenced in the sweep
section at the bottom; OPERATOR = needs credentials or a production
environment and cannot land as a commit.

## Setup

- **S1 — no README, no LICENSE.** Public repo, default all-rights-reserved,
  no entry document. → FIXED (README + MIT).
- **S2 — zero dependency governance.** No dependabot/renovate config; the
  5-major upgrade earlier was manual. → FIXED (dependabot.yml).
- **S3 — `engines: >=24` locks out Node 22 LTS contributors** while the
  production runtime is decided by Vercel, not this field. → FIXED (>=22).
- **S4 — code cites a repo path that does not exist**
  (`src/components/pages/MentorTablePage.tsx:516` →
  `.harness/nodes/deadcode-audit/eval.md`, directory untracked). → FIXED.

## Code structure

- **ST1 — MentorTablePage.tsx still 2,060 lines** after two extraction
  rounds: ~20 panel useStates, seat math, rotation DOM writes, a 75-key
  inline t bundle. → FIXED (round three: seat math →
  `features/mentorTable/seatLayout.ts` with its own unit tests, rotation →
  `useMentorRotation`; page at ~1,950 lines, now orchestration rather than
  borrowed math — accepted as the composition root).
- **ST2 — hook homes are inconsistent**: `useSessionFlow` in
  `components/pages/`, `useMentorNotes` in `components/mentorTable/hooks/`;
  `ConversationTurn` type lives inside a hook module. → FIXED.
- **ST3 — DI knot relocated, not resolved**: the session hook takes 11
  options, 6 of them TDZ-evasion arrow wrappers. → FIXED (options rework).
- **ST4 — identity semantics relay through three hop points**
  (page → useSessionFlow → useMentorNotes). → FIXED (mentorIdentity.ts).
- **ST5 — api/mentor-table.js: a 416-line single async handler.** → FIXED
  (decomposed into named steps).

## Code quality

- **Q1 — fabricated mentor speech**: useMentorNotes seeds
  `generateFollowup(...)` as the default reply and the catch path keeps it;
  note threads present invented text with no source marker. → FIXED.
- **Q2 — validation double standard**: handleGenerate clamps to 5,000
  code points, handleReplyAll does not clamp at all. → FIXED.
- **Q3 — a contract test regex-parses page source text**
  (api/__tests__/mentor-table.test.js readFileSync + MAX_PEOPLE grep) —
  tests typography, not behavior. → FIXED (shared constant).
- **Q4 — rate-limit bucket eviction labeled "LRU-ish" is insertion-order
  arbitrary drop** (lib/security.js) — IP rotation evicts legitimate
  buckets. → FIXED (real LRU).
- **Q5 — unmount-timing invariant maintained by comments across 7 scattered
  isMountedRef checks.** → FIXED (one lifecycle guard hook).

## Testing

- **T1 — the real-LLM path is skipped in CI** (valid-data e2e gates on a
  secret). The degradation contract can be pinned without secrets. → FIXED
  (degradation.spec.ts runs against the real server with no key and pins
  the whole honest-fallback chain in a browser); the with-key nightly
  remains OPERATOR.
- **T2 — the 95% coverage gate is carried by module mocks**; page tests
  mock the entire mentorApi module. → FIXED (integration layer over real
  modules, only fetch mocked; the existing mock-driven suites stay).
- **T3 — 7 e2e specs vs 991 unit tests**; the integration seams are
  under-covered at browser level. → FIXED (degradation + a11y e2e added).
- **T4 — browser-level a11y never executed**; jsdom axe is a shadow proof.
  → FIXED (session-phase axe matrix over theme×mode×language plus
  phone-width passes, run on a real browser); real-device matrix remains
  OPERATOR.
- **T5 — perf budgets loosened 2.5x for CI hardware** — too wide to catch
  regressions. → FIXED (re-baselined from local measurements).

## Product quality

- **PR1 — privacy posture is "warn the user to self-censor" instead of
  disclosing what the product does**: no statement that text is forwarded
  to a third-party LLM API, no retention statement. → FIXED (honest copy
  in five locales).
- **PR2 — aiDisclaimer is the only hardcoded i18n string** (isZh ternary in
  the page): es/ja/ko users read an English disclaimer, and
  no-missing-i18n-key is blind to hardcoded strings. → FIXED.
- **PR3 — the fabricated replies break past the disclaimer's own claim**:
  "AI-simulated perspective" describes the live path; invented follow-ups
  are not simulations. → FIXED (with Q1).
- **PR4 — degradation disclosure is inconsistent**: the desktop badge does
  not cover note threads or every fallback path. → FIXED (uniform marker).
- **PR5 — production capacity has zero real evidence**: load numbers are
  MacBook + mock upstream; the ~94% shed figure is arithmetic. → OPERATOR
  (needs a deployed environment).
